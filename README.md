# NewTok

Prototipo funcional (sin backend, datos mock) de un clon de las mecánicas principales de TikTok. Hecho con React Native + Expo + expo-router, siguiendo la metodología Spec-Driven Development.

- `spec.md` — qué se construye (historias de usuario, pantallas, criterios de aceptación, fuera de alcance).
- `plan.md` — cómo se construye (arquitectura, modelos de datos, navegación).
- `tasks.md` — tareas atómicas y verificables.
- `AGENTS.md` — convenciones y reglas para el agente de IA.
- `PROCESO.md` — documento del proceso (investigación, prompts, correcciones, conclusiones).

## Cómo correr el proyecto
1. Instalar dependencias: `npm install`
2. Iniciar el servidor de desarrollo: `npx expo start`
3. Escanear el QR con **Expo Go** en un teléfono real.
